# YONG-YI — Ultimate Interactive Digital Experience

A personalized digital world for letters, memories, storytelling, fantasy environments, and shared experiences.

## Project status

- **Phase 0:** Documentation baseline committed and verified.
- **Phase 1:** Initial Next.js foundation and interactive 2D experience preview implemented on `feat/phase-1-foundation`.
- **Application state:** Preview-only. Authentication, private persistence, real content management, and deployment are not configured.
- **Content integrity:** No real memories, dates, messages, or photographs are generated by the application.
- **Default branch:** `main`; Phase 1 work is isolated to a feature branch.

## Preview routes

- `/` — project landing and four product pillars.
- `/letter` — reserved for owner-authored letter content.
- `/memories` — filterable illustrative memory cards.
- `/journey` — milestone placeholders without invented dates.
- `/world` — keyboard-accessible interactive 2D fantasy scene preview.
- `/creator` — readiness notice; not an authenticated admin interface.

All sample cards are placeholders. Do not enter real personal data.

## Technology baseline

- Next.js 16.4.6
- React / React DOM 19.3.1
- TypeScript 5.9.3
- Tailwind CSS 4.3.5
- Vitest 5.1.1

Versions are pinned in `package.json`, and the generated `package-lock.json` (lockfileVersion 3) is committed. `npm ci` is used by CI for reproducible installation. GitHub Actions has passed lint, typecheck, unit tests, and the production build for the current foundation branch.

## Local development

Requires Node.js 20.9 or newer; Node 24 is the project development baseline.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Quality commands:

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

## Privacy and security boundary

The repository is currently public. Do not commit real letters, private photographs, personal messages, access tokens, passwords, Supabase service-role keys, or other secrets. No private database or media storage is connected.

Creator Studio is currently informational only and must not be treated as a secure admin area. Authentication and authorization must be completed before private content is entered.
